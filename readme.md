# Jeu du Memory

> Note : Ce projet est un projet de cours universitaire.

## Présentation :
Ce projet est un jeu de Memory développé en JavaScript, HTML et CSS.
<br>
Le but du jeu est de trouver toutes les paires de cartes identiques en un minimum de coups et de temps.

## Technologie utilisée :
- HTML
- CSS
- JavaScript

## Fonctionnalités :
- Mélange aléatoire des cartes à chaque partie via l'algorithme de Fisher-Yates.
- Affichage du nombre de coups et du temps écoulé.
- Implémentation de l'API [Picsum](https://picsum.photos/)
- Gestion du score et du meilleur score via le stockage local (localStorage).
- Affichage d'un message de victoire lorsque toutes les paires sont trouvées.
- Affichage de confettis lors de la victoire.

## Installation :
1. Clonez le dépôt GitHub : `git clone https://github.com/gabidut/r301-memory`
2. Ouvrez le fichier `index.html` (ou utilisez LiveServer) dans votre navigateur pour jouer au jeu.
